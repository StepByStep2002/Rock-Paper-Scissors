# Rock-Paper-Scissors

Updated version on the game, now has UI instead of being played in the console.

This is a simple JavaScript game that is played by pressing buttons. 
You choose Rock, Paper or Scissors by pressing buttons and then computer also randomly makes it's choice. 
This game is played until either side reaches 5 points.

Game keeps track of both opponents' choices, shows their score and declares the winner who reached 5 points score.

Pseudocode of the game
//Computer randomly chooses a number between 0 and 2
//The chosen number get assigned a string with Rock, Paper or Scissors
//Human presses the button with their choice
//Declare variables for players' score
//Write a function that takes both choices, plays a single round and declares it's result with increasing winner's score
//Make a function that ends the game when either player reaches 5 points and declares the winner of the game
